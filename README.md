# Bruno Tavares — Landing Page

Landing page em React + Vite baseada na identidade visual da logo oficial fornecida.

## Rodar localmente

```bash
npm install
npm run dev
```

Depois abra o endereço exibido pelo Vite.

## Build

```bash
npm run build
```

## Estrutura

- `src/App.jsx`
- `src/components/`
- `src/styles.css`
- `public/logo-bruno-tavares.png`

O conteúdo profissional foi mantido somente nas informações fornecidas. O bloco "Sobre mim" possui um placeholder para substituição futura.
